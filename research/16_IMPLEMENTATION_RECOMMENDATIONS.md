# 16. TOP 30 Implementation Recommendations

Дата: 11.09.2026. Порядок відповідає [17_PRODUCT_ROADMAP.md](17_PRODUCT_ROADMAP.md). Для кожного пункту вказано **простішу альтернативу**, яку розглянуто за правилом ponytail, і чому її недостатньо (або чому вона і є рішенням).

Складність: **S** — до дня, **M** — 2–5 днів, **L** — тиждень і більше.

---

### 1. Дата в боті за часовим поясом користувача
- **Що:** бот визначає «сьогодні» за TZ сервера. Треба рахувати за TZ користувача.
- **Звідки / джерело:** власний код (`server/bot-ai.js:14` `todayISO()` через `new Date()`, використання в `server/app.js:137`; Roo вже рахує правильно — `server/roo.js:167`). Патерн: ezbookkeeping `pkg/api/large_language_models.go` (`GetClientTimezone`).
- **Чому:** запис «кава 120» о 00:30 за Києвом на UTC-хості (Railway, **UNVERIFIED**) отримає вчорашню дату, а блок денного плану в боті — неправильний день.
- **Як:** `user_settings.timezone` (IANA). Mini App при старті шле `Intl.DateTimeFormat().resolvedOptions().timeZone`. `todayISO(tz)` через `Intl.DateTimeFormat('en-CA', {timeZone: tz})`.
- **Файли:** `server/db/migrations/007_user_timezone.js`, `server/bot-ai.js`, `server/app.js`, `server/allowance.js` (`weekdayIndex` також залежить від TZ), `web/telegram-adapter.js`, `server/test/unit-dates.test.js`.
- **Складність:** S. **Ризики:** користувачі, які ще не відкривали Mini App, лишаються без TZ → fallback `Europe/Kyiv`.
- **Результат:** правильні дати й денний план у боті.
- **Простіша альтернатива:** змінна `TZ=Europe/Kyiv` на сервері. Швидко, але ламається для користувачів з інших поясів. Прийнятна як тимчасовий крок у той самий день.

### 2. Ліміти AI в PostgreSQL + облік `usage`
- **Що:** перенести `usage` Map у таблицю `ai_usage`, записувати токени, латентність і вартість.
- **Звідки:** `server/ai.js:85-114`. Референс — `animir/node-rate-limiter-flexible` (`RateLimiterPostgres`).
- **Чому:** ліміти обнуляються при рестарті й деплої (OWASP LLM10). Немає даних про вартість.
- **Як:** `INSERT … ON CONFLICT (user_id, day) DO UPDATE SET count = count + 1 … WHERE count < limit RETURNING`. Після відповіді — `UPDATE tokens_in, tokens_out, cost_usd`.
- **Файли:** `server/ai.js`, `server/db/migrations/008_ai_usage.js`, `server/app.js`.
- **Складність:** S. **Ризики:** зайвий запит до БД на кожен AI-виклик (мізерно).
- **Результат:** стійкі ліміти + дашборд вартості AI.
- **Простіша альтернатива:** бібліотека rate-limiter-flexible. Дає ліміти, але не облік токенів. Власна таблиця закриває обидва завдання.

### 3. Security-заголовки + перевірка захисту від чужих доменів
- **Що:** CSP (спершу Report-Only), `nosniff`, `Referrer-Policy`, `Permissions-Policy`, `frame-ancestors` для клієнтів Telegram. Перевірити, що Mini App не викликає методи з інших доменів (Bot API 10.2, з 20.07.2026).
- **Звідки:** [10 §3](10_SECURITY.md), перелік заголовків helmet.
- **Чому:** зараз заголовків немає зовсім (пошук у `server/` порожній).
- **Як:** функція `securityHeaders(res)` у `staticFile` і `json`.
- **Файли:** `server/app.js`, `server/lib/http.js`.
- **Складність:** S. **Ризики:** зламати вбудовування в Telegram Web → спершу Report-Only, тест на всіх клієнтах.
- **Результат:** базовий захист від XSS і clickjacking.
- **Простіша альтернатива:** helmet. Це Express-middleware, для `node:http` рядки простіше поставити самому.

### 4. Evals для парсера й Roo
- **Що:** набір 50–100 кейсів (українська мова, голос, суржик, кілька операцій, prompt injection) → очікуваний JSON або виклик інструмента.
- **Звідки:** promptfoo (MIT, ★25,021). Референси: Sure `.github/workflows/llm-evals.yml`, бенчмарк Cleo.
- **Чому:** зміна моделі чи промпту зараз перевіряється вручну. Evals також відповідають, чи можна перейти на дешевшу gpt-oss-20b.
- **Як:** `promptfooconfig.yaml` з провайдером через той самий `AI_BASE_URL`, запуск `npx promptfoo eval` локально або в CI.
- **Файли:** `server/test/evals/` (нова папка), `package.json` (скрипт).
- **Складність:** S–M. **Ризики:** витрати на прогони (центи).
- **Результат:** вимірювана точність (цілі: ≥95% сума, ≥90% категорія).
- **Простіша альтернатива:** `node:test` з мок-відповідями. Перевіряє нормалізатори, але не модель. Використати обидва.
