# 07. UX/UI Research: дизайн-система, анімації, мікровзаємодії, чат, онбординг

Дата: 11.09.2026. Метрики бібліотек — у [02_GITHUB_RESEARCH.md](02_GITHUB_RESEARCH.md) §4.7–4.8.

## 1. Дизайн-система: рішення

**Зараз** (`design-system/kopiyka-telegram-mini-app/MASTER.md`, v2.0): семантичні токени `--app-*` з fallback на `themeParams` Telegram, шрифти Unbounded (суми) та Onest (інтерфейс), сітка 4 px, радіуси 14/22/26, мінімальна ціль дотику 44 px, `prefers-reduced-motion`. Це вже зрілий підхід, і він **сумісний з Telegram без жодної бібліотеки**.

| Система | Потребує | Для нас | Вердикт |
|---|---|---|---|
| shadcn/ui (★123,564) | React + Tailwind | анатомія компонентів, стани, a11y | **INSPIRE** |
| Radix / Base UI / React Aria | React | патерни доступності (фокус у діалогах, roving tabindex) | **INSPIRE** (React Aria — найкраща документація a11y) |
| Mantine / Chakra / MUI | React | — | **IGNORE** |
| daisyUI / Tailwind | збирач + Tailwind | утилітарні класи замість 125 KB CSS | IGNORE зараз: переписування всього CSS заради мінусу, якого немає |
| Konsta UI | React / Vue / Svelte | iOS/Material-вигляд | IGNORE |
| Framework7 / Ionic | заміна каркаса | мобільні компоненти | IGNORE (переписування) |
| Web Awesome (★1,311) | Web Components | можна у vanilla | IGNORE: свій набір уже є |
| Open Props (★5,513) | CSS | шкала токенів | **INSPIRE** (назви й шкали) |
| TelegramUI (★855) | React | нативний Telegram-вигляд | **INSPIRE**: брати візуальні рішення, не код |
| Lucide / Tabler / Phosphor | — | іконки | **USE як статичні SVG** (скопіювати потрібні 20–30 файлів, без runtime-бібліотеки; `lucide` як npm-пакет займає 99.3 KB gzip) |

**Висновок (ponytail):** найпростіше рішення, що працює, вже реалізоване. Жодна UI-бібліотека не дасть переваги, що виправдала б міграцію. Інвестувати варто в компоненти всередині своєї системи: bottom sheet, картки дій, чипи.

## 2. Навігація

- `MASTER.md` описує **3 пункти** dock-навігації (Огляд, Кишені, Помічник Roo). У `web/src/markup.html` є 6 екранів: `view-overview`, `view-journal`, `view-analytics`, `view-pockets`, `view-roo`, `view-cabinet`. Треба узгодити документацію і реалізацію: журнал і аналітика всередині «Огляду» (сегментований перемикач), кабінет у шапці.
- **Command bar за патерном Raycast:** одне поле «Що сталося?» на «Огляді». «кава 120» — це запис, «скільки на кафе?» — питання до Roo. Логіка вже є в `routeBotMessage` (`server/bot-ai.js:326`). Треба повторно використати її в застосунку, щоб у боті й у Mini App працювала одна модель введення.
- **BackButton** уже закриває внутрішні екрани (✓ UI-аудит). Він має закривати й bottom sheets.

## 3. Швидке додавання: головна механіка продукту

| Елемент | Рішення | Джерело |

Тап заповнює рядок, другий тап зберігає | HN-коментар до ExpenseOwl: «predictive form filling… for "Gas" I always made the title "Gas"». ## 4. Бюджетні моделі: UX-порівняння

| Модель | Приклад | Плюси | Мінуси | Для «Копійки» |
|---|---|---|---|---|
| Місячний бюджет | Revolut, Wallet | простий | не каже, «скільки можна сьогодні» | базовий рівень |
| Ліміти категорій | Monarch, «Копійка» ✓ | зрозуміло | потребує налаштування | ✓ є; додати сповіщення 80/100% |
| **Rolling (перенос залишку)** | Sure `budget/rollover_calculator.rb`, Actual `BalanceWithCarryover.tsx` | справедливо до нерівних місяців | складніше пояснити | **ADD як опцію** для лімітів категорій |
| Envelope | Actual `budget/envelope.ts`, OpenBudgeteer | дисципліна | крута крива навчання | IGNORE як режим за замовчуванням |
| Zero-based | YNAB ($109/рік, безкоштовні воркшопи для навчання) | потужно | потребує навчання | IGNORE |
| **Dynamic / daily allowance** | «Копійка» ✓ (`server/allowance.js`: накопичений план від початку місяця мінус витрати) | «скільки можна сьогодні» — найспокійніша відповідь | залежить від тижневого плану | **Головна відмінність продукту. Лишити героєм «Огляду»** |

Monzo Salary Sorter (✓ help center) показує, що автоматичний розподіл зарплати по «горщиках» у день виплати — масова механіка. У нас є `salary_schedule_days` і «кишені», тож це природне продовження (див. 14).

| Бібліотека | gzip | Статус | Вердикт |

| Motion (★33,557) | 44.5 KB | є vanilla API | IGNORE: дублює GSAP |
| AutoAnimate (★13,915) | 3.2 KB | — | IGNORE: дублює GSAP Flip |
| anime.js v4 (★72,781) | 39.3 KB | — | IGNORE: дублює GSAP |

| dotlottie-web (★875) | — | активний | INSPIRE: лише для рідкісних святкувань на віхах, з лінивим завантаженням |

## 6. Мікровзаємодії

| Взаємодія | Рішення | Бібліотека |
|---|---|---|
| Анімація чисел | GSAP tween значення + `font-variant-numeric: tabular-nums` (цифри не «стрибають») | GSAP (є). `number-flow` (★7,690, vanilla web component) як INSPIRE для ефекту «прокручування цифр» |
| Анімація балансу | лише при **зміні** значення, не на кожен рендер. Тривалість ≤ 400 мс | GSAP |
| Прогрес (ліміти, цілі, денний план) | CSS-транзиції `stroke-dashoffset` / `width` (донат уже на `stroke-dasharray`, `app.js:1315`) | CSS |
| Переходи категорій | GSAP Flip | є |
| Свайп рядка журналу | Pointer Events + `transform`, поріг 30% ширини. На час жесту `disableVerticalSwipes()` | без бібліотеки (`use-gesture` не оновлювався з 2024-03) |
| Жести транзакції | long-press, щоб редагувати, + `impactOccurred('medium')` | нативно |
| Bottom sheets | нативний `<dialog>` + CSS `scroll-snap`. Закриття BackButton-ом | INSPIRE: `pure-web-bottom-sheet` (MIT, v1.0.0 від 06.2026). `vaul` — лише React |
| Тости | свій (кілька рядків) | `sonner` — лише React |

**Мапа haptics:**

| Подія | Виклик |
|---|---|
| тап чипа, клавіші, пункту навігації | `impactOccurred('light')` |
| перемикання категорії чи сегмента | `selectionChanged()` |
| успішне збереження | `notificationOccurred('success')` (✓ частково) |
| перевищення ліміту або денного плану | `notificationOccurred('warning')` |
| помилка мережі чи валідації | `notificationOccurred('error')` |
| long-press, свайп за поріг | `impactOccurred('medium')` |

## 8. Онбординг за 30–60 секунд

Урок Duolingo (✓ deconstructoroffun, 15.05.2026): streak стає частиною **першої сесії ще до реєстрації**, бо перша дія має статися до будь-яких налаштувань.

| Крок | Час | Екран |
|---|---|---|
| 1 | 0–10 с | «Що ви купили сьогодні?» Поле з прикладами-чипами «кава 120», «продукти 450» → зберегти → коротке святкування |
| 2 | 10–25 с | «Скільки комфортно витрачати в день?» Число або «пропустити». Пояснення: «це і є "Сьогодні можна"» |
| 3 | 25–40 с | «Записуйте ще швидше»: кнопка `addToHomeScreen` і посилання «пишіть боту так само» |
| 4 | 40–60 с | «Огляд» з першим записом і денним планом |

Онбординг уже є (коміт `96a5535`, «onboarding and bank statement import»). Варто порівняти його з цим сценарієм за метрикою «час до першого запису» (див. 08 §3).

## 9. Персоналізація

- Чипи «повторити» (§3).
- Власні категорії й емодзі ✓.
- Віджети «Огляду»: сховати або змінити порядок карток (зберігати в `user_settings.extra_settings`).
- Адаптивні підказки Roo за подіями (день зарплати, перевищення, неділя ввечері → «Підсумок тижня?»).
- Нагадування «запишіть витрати» **лише** якщо сьогодні немає жодного запису, лише opt-in і у вибраний час. Потрібен часовий пояс користувача (див. 09).
