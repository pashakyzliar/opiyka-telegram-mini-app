# Evals: розбір тексту в транзакцію

Ці тести перевіряють **модель**, а не код. Юніт-тести (`npm test`) ловлять
регресії в нормалізаторах; evals ловлять регресії в промпті та зміну поведінки
після оновлення моделі.

## Коли запускати

- перед зміною `AI_MODEL`;
- після будь-якої правки `buildWritePrompt` у `server/bot-ai.js` або системного
  промпту в `server/ai.js`;
- коли думаєте перейти на дешевшу модель (розкоментуйте другого провайдера в
  конфігу й порівняйте таблицю результатів).

## Запуск

```sh
AI_BASE_URL=https://... AI_KEY=... npm run evals
```

`promptfoo` ставиться через `npx` і не додається в залежності проєкту: це
інструмент розробника, а не частина застосунку.

## Орієнтири

- сума: ≥95% правильних;
- категорія: ≥90% правильних серед тих, де модель не повернула `null`;
- `null` замість вгаданої категорії — **правильна** поведінка (далі запитає бот);
- кейс з prompt injection має лишати суму 120.

## Важливо

Промпт у `promptfoo` продубльовано з `server/bot-ai.js`. Якщо міняєте промпт у
коді — оновіть і конфіг, інакше evals перевірятимуть не те, що працює в
продакшені. Дата в промпті зафіксована (`2026-09-12`), щоб кейс «вчора» був
відтворюваним.
